# 소상공인 AI 홍보마케팅 교육 홍보영상 기획안

## 1. 기획 개요

| 항목 | 내용 |
|---|---|
| 영상 목적 | 소상공인 대상 AI 활용 홍보마케팅 교육 모집 |
| 타깃 | 홍보·마케팅에 시간과 비용을 쓰기 어려운 소상공인 (식당, 카페, 숙박, 소매, 공방 등) |
| 핵심 메시지 | "효과적인 홍보마케팅, AI 활용은 선택이 아니라 필수입니다" |
| 톤앤매너 | 밝고 신뢰감 있는 여성 아나운서 톤, 쉬운 말, 부담 없는 분위기 |
| 권장 길이 | **메인 60초** (유튜브·카카오·페이스북용) + **30초 컷다운** (릴스·쇼츠·카톡 공유용) |
| 화면비 | 16:9 메인 제작 후 9:16 세로 버전 리사이즈 |

### 길이 제안 근거
- 15~30초: 후킹은 되지만 "단톡방 자료 제공·복습 영상·실습 위주"라는 3가지 차별점을 다 담기 어려움
- 60초: 문제 제기 → 해결 → 차별점 3가지 → 후킹 → 신청 안내까지 자연스럽게 담기는 최적 길이
- 90초 이상: 소상공인이 카톡으로 받았을 때 끝까지 볼 확률이 급격히 떨어짐

## 2. 스토리 구조 (60초 기준)

```
[0~8초]   후킹 : "이거, 남 얘기 아닙니다"
[8~20초]  공감 : 홍보하고 싶은데 시간도 돈도 없는 사장님의 현실
[20~35초] 해결 : AI로 10분 만에 홍보물 뚝딱, 실습 장면
[35~50초] 차별점 : 단톡방 자료 제공 · 복습 영상 · 실습 위주
[50~60초] 클로징 : "선택이 아니라 필수" + 신청 안내
```

## 3. 씬별 콘티 + 나레이션 (메인 60초)

### 씬 1. 후킹 (0~8초)
**화면**
- 검은 화면 → 스마트폰에서 SNS 게시물, 블로그 글, 홍보 이미지가 빠르게 넘어감
- 자막 크게: **"요즘 잘되는 가게, 다 이걸 씁니다"**

**나레이션**
> 요즘 손님 많은 가게들, 비결이 뭘까요?
> 홍보 잘하는 사장님들은 이미 AI를 쓰고 있습니다.

---

### 씬 2. 공감 (8~20초)
**화면**
- 영업 마감 후 혼자 남은 사장님, 휴대폰 들고 한숨 (인스타 글쓰기 화면에서 멈춰 있음)
- 자막: "뭐라고 써야 하지…" / "사진은 어떻게 만들지…" / "광고비는 부담되고…"

**나레이션**
> 장사하기도 바쁜데, 홍보까지 직접 하려니 막막하시죠?
> 글은 뭐라고 써야 할지, 사진은 어떻게 만들지,
> 그렇다고 광고 대행을 맡기자니 비용이 부담되고요.

---

### 씬 3. 해결 (20~35초)
**화면**
- 같은 사장님, 이번엔 휴대폰에 프롬프트 한 줄 입력 → 홍보 문구, 메뉴 소개글, 이벤트 이미지가 순식간에 생성
- 화면 분할: 왼쪽 '프롬프트 입력' / 오른쪽 '결과물 완성'
- 자막: **"프롬프트 한 줄, 홍보물 10분 완성"**

**나레이션**
> 이제 AI에게 한 줄만 말해보세요.
> 인스타 문구, 블로그 글, 이벤트 포스터까지
> 어렵지 않게, 10분이면 충분합니다.

---

### 씬 4. 차별점 3가지 (35~50초)
**화면** — 아이콘 3개가 순서대로 등장 (각 5초)
1. 💬 **단톡방** : 카톡 단톡방 화면, 프롬프트·교육자료 파일이 올라오는 모습
2. ▶️ **복습 영상** : 집에서 교육 영상 다시 보는 사장님
3. ✋ **실습 위주** : 교육장에서 각자 휴대폰·노트북으로 직접 만들어보는 장면, 결과물 보고 웃는 표정

**나레이션**
> 이 교육은 이론이 아닙니다.
> 배운 그날 바로 쓸 수 있는 **실습 중심** 교육이고요,
> 수업에서 쓴 **프롬프트와 교육자료는 단톡방으로** 바로 드립니다.
> 놓친 내용은 **교육 영상으로 언제든 복습**할 수 있습니다.

---

### 씬 5. 클로징 후킹 + 신청 안내 (50~60초)
**화면**
- 화면 가득 자막: **"AI 활용, 이제 선택이 아니라 필수입니다"**
- 이어서 교육명 / 일정 / 장소 / 신청 QR·전화번호 / 주최 로고

**나레이션**
> 효과적인 홍보마케팅을 위한 AI 활용,
> 이제 선택이 아니라 **필수**입니다.
> 지금 바로 신청하세요.

---

## 4. 나레이션 전문 (60초 / 약 220자 / 아나운서 속도 기준)

> 요즘 손님 많은 가게들, 비결이 뭘까요? 홍보 잘하는 사장님들은 이미 AI를 쓰고 있습니다.
>
> 장사하기도 바쁜데, 홍보까지 직접 하려니 막막하시죠? 글은 뭐라고 써야 할지, 사진은 어떻게 만들지, 그렇다고 광고 대행을 맡기자니 비용이 부담되고요.
>
> 이제 AI에게 한 줄만 말해보세요. 인스타 문구, 블로그 글, 이벤트 포스터까지, 어렵지 않게 10분이면 충분합니다.
>
> 이 교육은 이론이 아닙니다. 배운 그날 바로 쓸 수 있는 실습 중심 교육이고요, 수업에서 쓴 프롬프트와 교육자료는 단톡방으로 바로 드립니다. 놓친 내용은 교육 영상으로 언제든 복습할 수 있습니다.
>
> 효과적인 홍보마케팅을 위한 AI 활용, 이제 선택이 아니라 필수입니다. 지금 바로 신청하세요.

**나레이션 디렉션**
- 여성 아나운서 톤, 뉴스보다 살짝 따뜻하고 부드럽게 (홈쇼핑처럼 급하지 않게)
- 씬 2(공감)는 살짝 낮고 천천히 → 씬 3부터 밝고 경쾌하게 올라감
- "필수입니다"는 또박또박 힘주어, 마지막 "지금 바로 신청하세요"는 미소 띤 목소리로
- TTS 사용 시 추천: 타입캐스트·클로바더빙·일레븐랩스 '아나운서/뉴스' 계열 여성 보이스, 속도 0.95~1.0배

## 5. 30초 컷다운 버전 (릴스·쇼츠·카톡 공유용)

```
[0~5초]   후킹   : 요즘 잘되는 가게, 다 이걸 씁니다
[5~12초]  공감   : 홍보, 막막하시죠?
[12~20초] 해결   : 프롬프트 한 줄, 홍보물 10분 완성
[20~26초] 차별점 : 실습 위주 · 단톡방 자료 · 복습 영상
[26~30초] 클로징 : 선택 아닌 필수, 지금 신청
```

**나레이션 (약 110자)**
> 요즘 손님 많은 가게들, 이미 AI를 쓰고 있습니다.
> 홍보, 막막하셨죠? 이제 AI에게 한 줄만 말해보세요. 홍보물 10분이면 끝납니다.
> 이론 말고 실습으로, 자료는 단톡방으로, 복습은 영상으로.
> AI 활용, 이제 선택이 아니라 필수입니다. 지금 신청하세요.

## 6. 자막·그래픽 가이드

| 구분 | 가이드 |
|---|---|
| 핵심 자막 | 씬당 1개, 12자 이내, 화면 하단 굵은 고딕 |
| 강조 컬러 | 메인 1색(예: 주황·파랑) + 검정·흰색만 사용, 3색 넘기지 않기 |
| 폰트 | 프리텐다드·나눔스퀘어·G마켓산스 등 무료 굵은 고딕 |
| BGM | 밝고 경쾌한 어쿠스틱/팝 (씬 2만 잠시 톤다운) |
| 효과음 | 씬 3 결과물 생성 순간 '띠링' 효과음으로 전환 강조 |
| 엔딩 카드 | 교육명·일시·장소·신청 QR·문의 전화 5초 이상 노출 |

- [ ] 주최·주관 기관 로고

- [ ] 지역명 삽입 여부 (예: "남원 소상공인 여러분" — 지역 타깃이면 첫 문장에 넣으면 클릭률 상승)

## 8. 활용 팁

- **후킹 A/B 테스트**: 씬 1 자막을 "요즘 잘되는 가게, 다 이걸 씁니다" vs "아직도 홍보글 직접 쓰세요?" 두 가지로 만들어 반응 좋은 쪽 사용
- **카톡 배포용**: 30초 세로 버전 + 첫 프레임을 썸네일로 활용
- **후속 영상**: 교육 후 수강생 후기 15초 영상을 만들면 다음 회차 모집에 가장 효과적
