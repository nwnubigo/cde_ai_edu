# 소상공인 AI 홍보마케팅 교육 안내 웹사이트 기획안

## 1. 기획 개요

| 항목 | 내용 |
|---|---|
| 사이트 목적 | 소상공인 대상 AI 홍보마케팅 교육을 알리고 **신청 전환**을 만드는 것 |
| 사이트 성격 | 정보 나열형이 아닌 **모집 랜딩페이지 중심의 원페이지 사이트** + 보조 페이지 3개 |
| 핵심 목표(KPI) | ① 신청 완료 수 ② 카카오톡 채널/단톡방 유입 수 ③ 영상 시청 완료율 |
| 타깃 | 40~60대 소상공인(식당·카페·숙박·소매·공방·미용 등), 스마트폰으로 접속하는 비율 80% 이상 예상 |
| 핵심 메시지 | "효과적인 홍보마케팅, AI 활용은 선택이 아니라 필수입니다" (영상과 동일) |
| 도메인 | https://소상공인AI홍보마케팅.신청하기.com (영상에 삽입된 주소와 일치) |
| 톤앤매너 | 밝고 신뢰감 있는 톤, 큰 글씨, 어려운 용어 없음, 버튼은 크고 하나로 |

### 타깃 특성에서 나오는 설계 원칙
- **모바일 퍼스트**: 카톡으로 링크를 받아 스마트폰에서 열어본다. PC 화면은 부차적.
- **글자 크기 최소 18px**, 버튼 높이 56px 이상, 한 화면에 메시지 하나.
- **신청은 3분 안에**: 회원가입 없음, 입력 항목 최소화(이름·연락처·업종·희망 회차).
- **전화·카톡으로 바로 문의** 가능해야 함. 폼만 두면 이탈이 큼.
- **"내 이야기"라고 느끼게**: 업종별 사례(식당·카페·미용실…)를 눈에 보이게.

## 2. 사이트 구조 (사이트맵)

```
/                 메인 랜딩 (원페이지, 신청 전환의 90%가 여기서 발생)
/apply            신청 폼 (메인 CTA 클릭 시 이동, 또는 메인 하단에 임베드)
/curriculum       교육 커리큘럼 상세 (회차별 실습 내용, 준비물)
/faq              자주 묻는 질문
/notice           공지·회차 안내 (선택, 운영 여력 있을 때)
/complete         신청 완료 페이지 (단톡방 입장 안내 + 캘린더 등록)
```

원칙: 메뉴는 4개 이하. 상단 고정 바에는 로고 · 커리큘럼 · FAQ · **[신청하기] 버튼** 만.

## 3. 메인 랜딩페이지 섹션 설계 (위 → 아래 순서)

### 섹션 1. 히어로 (첫 화면)
- **헤드라인**: 요즘 잘되는 가게, 다 이걸 씁니다
- **서브**: 소상공인을 위한 AI 홍보마케팅 실습 교육 — 이론 말고, 배운 그날 바로 씁니다
- **배경**: 60초 홍보영상 자동재생(무음, 자막 포함) 또는 영상 썸네일 + 재생 버튼
- **CTA 버튼**: [지금 바로 신청하기] (노란색, 화면 하단에 항상 고정되는 스티키 버튼과 동일)
- **신뢰 배지 한 줄**: 정원 ○○명 · 무료(또는 수강료) · ○월 ○일 개강 · 남원(지역명)

### 섹션 2. 공감 (문제 제기)
- 제목: 홍보, 이래서 막막하셨죠?
- 카드 3개: "뭐라고 써야 하지…" / "사진은 어떻게 만들지…" / "광고비는 부담되고…"
- 한 줄 마무리: 장사하기도 바쁜 사장님이 홍보까지 다 하려니 당연히 힘듭니다.

### 섹션 3. 해결 (Before / After)
- 제목: AI에게 한 줄만 말해보세요. 10분이면 끝납니다.
- 좌우 비교: 왼쪽 "프롬프트 한 줄 입력" 화면 → 오른쪽 "인스타 문구 · 블로그 글 · 이벤트 포스터" 결과물
- 실제 교육에서 나온 결과물 캡처 3~4개(업종별) 슬라이드

### 섹션 4. 이 교육만의 3가지 (차별점)
| 아이콘 | 제목 | 설명 |
|---|---|---|
| ✋ | 이론이 아닌 실습 중심 | 각자 휴대폰·노트북으로 직접 만들어 그날 바로 가게에 씁니다 |
| 💬 | 단톡방으로 프롬프트·자료 제공 | 수업에서 쓴 프롬프트와 교육자료를 단톡방에 바로 올려드립니다 |
| ▶️ | 교육 영상으로 언제든 복습 | 놓친 내용은 영상으로 다시 보며 복습할 수 있습니다 |

### 섹션 5. 커리큘럼 요약
- 회차별 표 (예시, 실제 과정에 맞게 수정)

| 회차 | 주제 | 실습 결과물 |
|---|---|---|
| 1회 | AI 첫걸음 & 우리 가게 소개글 | 가게 소개문·메뉴 설명 |
| 2회 | 인스타·블로그 글쓰기 | 게시물 5개 + 해시태그 |
| 3회 | 홍보 이미지·포스터 만들기 | 이벤트 포스터 2종 |
| 4회 | 네이버 플레이스·리뷰 답글 | 리뷰 답글 템플릿 |
| 5회 | 짧은 홍보 영상 만들기 | 15초 쇼츠 1편 |
| 6회 | 나만의 프롬프트 노트 완성 | 업종별 프롬프트 모음집 |

- [커리큘럼 자세히 보기] 링크 → /curriculum

### 섹션 6. 교육 정보 (한눈에)
- 일정 · 시간 · 장소(지도 임베드) · 정원 · 수강료 · 준비물(스마트폰이면 충분) · 강사 소개
- 지도는 네이버/카카오 지도 임베드, "길찾기" 버튼

### 섹션 7. 수강생 후기 (있을 때만)
- 실명·업종·사진 동의 받은 후기 3개. 없으면 이 섹션은 넣지 않는다(가짜 후기 금지).
- 대안: "1기 모집 중 — 첫 수강생이 되어주세요" 문구로 대체

### 섹션 8. FAQ 요약 (5개)
- 컴퓨터를 잘 못해도 되나요? / 준비물은? / 비용은? / 결석하면? / 단톡방은 언제 들어가나요?

### 섹션 9. 마지막 CTA
- 큰 문구: AI 활용, 이제 선택이 아니라 필수입니다
- [지금 바로 신청하기] + [카카오톡으로 문의] + 전화번호(탭하면 바로 통화)

### 푸터
- 주최·주관 로고, 주소, 연락처, 개인정보처리방침 링크

## 4. 신청 폼 설계 (/apply)

| 항목 | 필수 | 형식 |
|---|---|---|
| 이름 | 필수 | 텍스트 |
| 연락처 | 필수 | 휴대폰 번호(자동 하이픈) |
| 업종 | 필수 | 선택형: 음식점 / 카페 / 소매 / 숙박 / 미용·뷰티 / 공방·제조 / 기타 |
| 상호명 | 선택 | 텍스트 |
| 희망 회차 | 필수 | 라디오 (1기 ○월, 2기 ○월…) |
| 알게 된 경로 | 선택 | 카톡 / 유튜브 / 지인 / 현수막 / 기타 |
| 개인정보 수집 동의 | 필수 | 체크박스 + 내용 보기 |

- 제출 후 `/complete`로 이동: "신청 완료! 아래 버튼으로 단톡방에 입장해주세요" + 카카오 오픈채팅 링크 + 일정 캘린더 추가 버튼
- 관리자에게 알림: 구글 시트 자동 기록 + 이메일/카톡 알림
- 구현 옵션: ① 구글폼 임베드(가장 빠름) ② Tally/Typeform ③ 자체 폼 + 구글 시트 연동(Apps Script)

## 7. 기술·제작 방식 제안

| 방식 | 장점 | 단점 | 추천 상황 |
|---|---|---|---|
| **A. 정적 원페이지 (HTML/CSS/JS) + 구글폼** | 가장 빠름, 무료 호스팅(Netlify/Vercel), 가볍고 빠름 | 공지 수정에 코드 수정 필요 | **1기 모집처럼 빠르게 띄울 때 (추천)** |
| B. 노코드 빌더 (아임웹·Wix·Framer) | 비개발자가 직접 수정 | 월 비용, 속도·자유도 제한 | 담당자가 직접 자주 고칠 때 |
| C. 워드프레스 | 공지·블로그 확장 쉬움 | 유지관리·보안 부담 | 교육이 정기 사업이 될 때 |

**추천: A안**으로 먼저 오픈하고, 반응이 확인되면 C안으로 확장.

기술 요소:
- 반응형(모바일 우선), 첫 화면 로딩 2초 이내(영상은 유튜브 임베드 지연 로딩)
- 한글 도메인 연결 + HTTPS
- 카카오톡 공유 시 미리보기(OG 이미지·제목·설명) 설정 — 카톡 배포가 주 유입이므로 필수
- 구글 애널리틱스 또는 네이버 애널리틱스로 신청 버튼 클릭 추적
- 접근성: 글자 확대해도 깨지지 않게, 색 대비 4.5:1 이상

## 8. 홍보영상과의 연계

- 히어로 영상: 60초 16:9 버전
- 카톡·인스타 공유용: 30초 세로 버전 + OG 이미지에 같은 헤드라인 사용
- 영상 엔딩 카드 URL = 사이트 도메인, 사이트 CTA 문구 = 영상 나레이션 마지막 문장으로 통일
- 영상 자막 문구("요즘 잘되는 가게, 다 이걸 씁니다" / "프롬프트 한 줄, 홍보물 10분 완성")를 사이트 섹션 제목으로 그대로 재사용 → 영상 보고 들어온 사람이 같은 메시지를 보게 됨

## 9. 제작 일정 (예시, 1주)

| 일차 | 작업 |
|---|---|
| 1일 | 콘텐츠·자산 확정(체크리스트), 문안 최종화 |
| 2~3일 | 메인 랜딩 + 신청 폼 제작, 모바일 점검 |
| 4일 | 커리큘럼·FAQ·완료 페이지, 카톡 미리보기·분석 도구 설정 |
| 5일 | 도메인 연결, 실기기 테스트(갤럭시·아이폰), 신청 알림 테스트 |
| 6~7일 | 오픈, 카톡·영상에 링크 배포, 첫 반응 보고 문구 조정 |

## 10. 오픈 후 운영 포인트

- 신청 버튼 클릭 대비 신청 완료율이 30% 미만이면 폼 항목을 더 줄인다
- 카톡 유입 대비 체류시간이 짧으면 히어로 헤드라인 A/B 교체("아직도 홍보글 직접 쓰세요?")
- 1기 종료 후 수강생 결과물·후기를 받아 섹션 3·7을 실제 사례로 교체 → 2기 전환율 상승
